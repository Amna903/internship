# Telehealth visits (fictional clinic)

Telehealth visits take place by video in the patient app. Patients should join 5 minutes before the start
time to check their camera and microphone. If the connection fails, the clinician calls the patient's phone
number on file and continues by phone. A telehealth visit can be changed to an in-person visit when
rescheduling, if a slot is available. Telehealth visits follow the same cancellation policy as in-person visits.
