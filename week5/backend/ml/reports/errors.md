# Error analysis: chosen no-show model

> Synthetic, educational data. Generated by `python -m ml.errors`; do not edit by hand.
> Model and threshold come from Step 4 ([metrics.md](metrics.md)) and are **not changed here**.
> Analysis uses the **validation** set (3,998 rows). Test numbers are for reporting only.

Model: **logreg_engineered (C=0.1)** · decision threshold **0.1688** (flag for an extra reminder)

## 1. The four outcomes

| | missed (no-show) | attended |
|---|---|---|
| **flagged** | 383 true positives | 1,206 false positives |
| **not flagged** | 263 false negatives | 2,146 true negatives |

Validation: precision 24.1% · recall 59.3% · false-positive rate 36.0% ·
flagged 39.7%. Test (reporting only): 388 TP · 1,187 FP · 262 FN · 2,115 TN.

What each error costs here:
- **False positive** (flagged, attended anyway): one unnecessary reminder message. Cheap.
- **False negative** (not flagged, then missed): no extra reminder for someone who needed it; a lost slot.
  Costlier.
That cost difference is why a threshold with modest precision and higher recall is acceptable for this
use, and why the output must never drive anything costly for the patient.

## 2. Calibration: can the probabilities be trusted?

Validation rows split into 10 equal-size bins by predicted probability. If the model is calibrated,
each bin's observed rate differs from its predicted rate only by sampling noise (standard error, "se").
A bin is flagged only if |z| = |gap| / se exceeds **2.81**: the Bonferroni limit that keeps the
chance of *any* false alarm across all 10 bins at 5%. (A plain 2-se rule per bin would raise
at least one false alarm about 40% of the time even for a perfect model.)

| bin | rows | predicted | observed | gap | se | z | |
|---|---|---|---|---|---|---|---|
| 1 | 400 | 5.1% | 5.5% | +0.4 pts | 1.1 pts | +0.32 | ok |
| 2 | 400 | 7.9% | 9.2% | +1.4 pts | 1.3 pts | +1.01 | ok |
| 3 | 400 | 10.1% | 10.2% | +0.2 pts | 1.5 pts | +0.11 | ok |
| 4 | 399 | 12.0% | 15.3% | +3.3 pts | 1.6 pts | +2.01 | ok |
| 5 | 400 | 14.0% | 9.5% | -4.5 pts | 1.7 pts | -2.57 | ok |
| 6 | 400 | 15.8% | 16.0% | +0.2 pts | 1.8 pts | +0.11 | ok |
| 7 | 399 | 18.0% | 19.0% | +1.0 pts | 1.9 pts | +0.54 | ok |
| 8 | 400 | 20.7% | 20.8% | +0.1 pts | 2.0 pts | +0.04 | ok |
| 9 | 400 | 24.7% | 21.8% | -3.0 pts | 2.2 pts | -1.37 | ok |
| 10 | 400 | 34.0% | 34.2% | +0.2 pts | 2.4 pts | +0.10 | ok |

Expected calibration error (row-weighted mean |gap|): **1.41 points**.

**No recalibration needed.** No bin's gap exceeds the noise limit (|z| ≤ 2.81 in every bin; largest |z| = 2.57). A naive per-bin 2-se rule would have flagged bin(s) 4, 5: exactly the kind of false alarm the adjusted limit exists to prevent.

## 4. Bias: age

| | 18-24 | 55-64 | gap |
|---|---|---|---|
| false-positive rate (attenders flagged) | 71.8% | 24.0% | **+47.8 pts** |
| recall (no-shows caught) | 85.4% | 41.9% | +43.4 pts |
| flagged | 75.3% | 26.0% | 2.9× |

**Cause.** Age is a real (planted) driver: 18–24-year-olds miss far more often. The model is right *on
average* for each group (compare "no-show rate" and "mean prediction" in §3), yet a young patient who would
have attended is 48 points more likely to be flagged than an older one.

Test set, reporting only: false-positive rate 18-24 69.6% vs 55-64 24.5%.

**Mitigation options considered:**

| option | effect (validation) | decision |
|---|---|---|
| (a) remove age from the model | PR-AUC 0.276 → 0.260; false-positive gap +47.8 → -9.7 pts | Not applied now (test set already used). A candidate for the next model version, with its own validation and test. |
| (b) a different threshold per age group | could equalise false-positive rates | **Rejected**: it deliberately treats people differently by age. |
| (c) supportive use only | the only action is an extra reminder; never refusal, penalty or priority | **Adopted.** A false positive costs one message. |

## 5. Model error vs unavoidable noise

Each outcome is a weighted coin flip, so some errors no model can avoid. With synthetic data we know
the true probability, so we can ask whether a model with *perfect* knowledge (same threshold) would have
made the same mistake.

| error | count | also made by perfect knowledge (unavoidable) | the model's own share |
|---|---|---|---|
| false negatives (missed no-shows) | 263 | 169 (64.3%) | 35.7% |
| false positives (flagged attenders) | 1,206 | 808 (67.0%) | 33.0% |

Most errors are the coin flip's, not the model's: even knowing the exact probability, you cannot tell
which of two 20% appointments will be missed.
